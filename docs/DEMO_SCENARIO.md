# Reproducible SIH Demo Scenario

## Purpose

Create one deterministic demonstration that can be run repeatedly during judging.

## Scenario

- Location: one selected demo dam and bounded downstream study area
- Scenario: Medium or Severe breach
- Terrain: one documented DEM
- Exposure: one documented settlement/road dataset

## Demo Steps

1. Start JalRakshak.
2. Select the demo dam.
3. Select a breach preset.
4. Review assumptions.
5. Run simulation.
6. Show simulation status.
7. Display flood extent.
8. Enable water-depth layer.
9. Move the time control.
10. Show affected settlements/roads.
11. Display risk statistics.
12. Export the result if implemented.

## Before SIH

Pre-run and cache a verified demo scenario if full ANUGA execution takes too long for live judging. Clearly label cached outputs as simulation results and explain when/how they were generated.

Do not alter scientific outputs simply to make the demo look better.
