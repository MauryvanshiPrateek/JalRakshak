# Product Requirements — JalRakshak

## Problem

A dam-break event can rapidly create downstream flooding. Decision-makers need understandable information about flood extent, depth, affected locations and risk.

## Product Goal

Build a reusable prototype that turns a dam-break scenario and geospatial terrain data into an interpretable flood-risk visualization.

## Primary Users

- Disaster-management teams
- Water-resource authorities
- Researchers
- Emergency planners
- Academic demonstrators

## MVP Success Criteria

A judge should be able to:
1. select a study area,
2. configure a breach,
3. run a simulation,
4. see flood propagation,
5. inspect water depth,
6. identify affected locations,
7. understand risk from one dashboard.

## Non-MVP

Do not initially attempt:
- nationwide operational deployment,
- automatic official emergency alerts,
- perfect breach prediction,
- live sensor networks,
- large-scale cloud HPC.

## Key UX Principle

The output must be understandable to a non-hydrologist.
