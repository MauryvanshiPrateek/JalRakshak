# JalRakshak — Sample / Demo Data

## Contents

This folder contains sample/mock data used for Phase 1 prototype demonstration.

> ⚠️ All data in this folder is **synthetic or illustrative**.
> It is generated procedurally in Python code (see `gis/` modules).
> It is NOT real survey data and must not be used for operational decisions.

## Files (generated in-memory — no files yet)

| Layer | Description | Generator | CRS |
|-------|-------------|-----------|-----|
| Flood Extent | Mock flood polygon based on weir formula | `gis/flood_extent.py` | EPSG:4326 |
| Risk Zones | Concentric risk bands from dam | `gis/risk.py` | EPSG:4326 |
| Settlements | Approximate urban/village points, Odisha | `gis/vector.py` | EPSG:4326 |
| Roads | Approximate road alignments, NH-53 region | `gis/vector.py` | EPSG:4326 |
| DEM | Synthetic elevation surface | `gis/dem.py` | EPSG:4326 |

## Demo Scenario

- **Dam:** Hirakud Dam (approximate coordinates: 21.525°N, 83.873°E)
- **River:** Mahanadi (approximate centreline)
- **Study area:** ~80 km downstream corridor
- **Population data:** Approximate estimates from public sources (not census-accurate)
